# 拉麵通專案文件

本目錄集中管理拉麵通專案的技術文件、架構決策與開發紀錄。

## 目錄

- `architecture/`：系統架構與流程圖
- `api/`：API 規格
- `database/`：資料庫設計
- `adr/`：架構決策紀錄
- `sprint/`：Sprint 文件
- `meeting/`：會議紀錄
- `assets/`：圖片與圖表
